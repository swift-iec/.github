# Swift IEC

Use this organization when you need a Swift implementation of an IEC standard. There is one package per specification, named `swift-iec-<number>`, which follows its source document as literally as possible under its own namespace, such as `IEC_61966`. The [repositories](https://github.com/orgs/swift-iec/repositories) list them by number. If several specifications govern your subject, use the unifying `swift-*-standard` package in [swift-standards](https://github.com/swift-standards). This is part of Layer 3 of the [Swift Institute](https://github.com/swift-institute).

> Swift IEC is an independent open-source project. It is not affiliated with, endorsed by, or sponsored by the International Electrotechnical Commission.
